# 판독기 성능
언제 읽나: 판독 모델을 다시 학습하거나 붙이는 방식을 바꿀 때, '정확도가 얼마나 되냐'는 질문에 답할 때. 확인일 2026-10-12

## 시험지
- 정답이 있는 실제 문의 캡처 28장 + 그걸 8가지로 망가뜨린 사본 224장(작게 75%·크게 130%·흐림·HDR·어둡게·JPEG 40·감마·섞음) = 252장 (`tools/ocrnet/degrade_full.py`, `test/private/compare-ocr.test.ts`)
- 맞힘 = 유지까지 12줄(블랙은 사용 이월 12줄까지) 1등 판독이 정답과 같음
