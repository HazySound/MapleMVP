# 문의 대응
언제 읽나: 문의 게시판에 새 글이 올라와 원인을 찾을 때, 운영 D1을 조회·수정할 때, 로컬 화면으로 재현할 때

## 결정
- 문의 답변 문구는 '~습니다'체, 사용자가 직접 다듬는다. Claude는 내용만 제안
- 운영 D1 조회는 한 사람 행씩, 개인 자료는 `docs/private`·`frontend/test/private`에만(커밋 안 함)

## 주의
- wrangler는 저장소 루트에서 실행한다(frontend에서 하면 인증 오류가 났다)
- 관리자 계정은 member.admin=1로 찾는다
- 캡처를 받을 때 이미지 칸은 `hex(data)`로 받아 파일로 푼다. jpeg는 PIL로 png로 바꿔 시험한다
- 고치기 전 코드로 문의자가 본 문구가 그대로 나오는지(diag.scans의 msg) 먼저 재현한다
- 문의는 게시판 밖(메일·인벤)으로도 온다. 숫자로 계정을 못 찾으면(저장값에 계산값은 없다) 닉네임을 받아 member.nick으로 찾는다. 로그인 전 브라우저에만 적은 자료는 서버에 없다(2026-11-05: 처음엔 못 찾고, 닉네임을 받은 뒤 그 사이 동기화된 값을 찾음)
- 한글이 든 SQL은 `--file`로 보내면 결과가 안 돌아온다. python subprocess로 `--command`에 넣어 바이트로 받아 utf-8로 푼다(Windows 콘솔 인코딩이 깨짐)
- 원인 설명은 화면 캡처만 보고 짐작하지 말고 운영 값으로 실제 계산 함수를 돌려 주별 숫자를 맞춘다. 충전 기록 id에는 적은 시각이 들어 있어(`ch` + Date.now() 36진수) 언제 무엇을 적었는지 순서를 뽑을 수 있다(2026-11-06 '두 배 잔액' 문의: 한 번은 '이번 주 충전 칸 때문'이라 짐작했고, 실제로는 지난 주 기록 중복이었다)
- 근거가 확실해도 남의 운영 저장값은 우리가 지우지 않고, 고칠 화면을 만든 뒤 본인에게 안내한다(동의 뒤에만 직접 수정)

## 현재 방식
- 2026-11-05 운영자 알림은 텔레그램 봇으로(사용자: 문의를 22시간 지나 보는 일이 많다). 카톡 '나에게 보내기'는 나와의 채팅이라 알림이 안 뜬다(사용자), 메일은 Workers에 SMTP가 없어 소켓 라이브러리가 필요해 뒤로 미룸. 봇 토큰은 캡처에서 옮겨 적으며 글자가 바뀌기 쉬워 getMe로 확인했다(0/O 혼동)
- 청약철회(2026-11-15, 문의 #34): 넥슨은 '사용' 줄을 그대로 두고 같은 purchaseId로 '철회' 줄을 더 적는다(운영자 계정 쪽지 50원으로 확인). 북마클릿(ver 3)이 둘을 결제번호로 짝지어 빼고 `withdrawn`으로 보내면, 앱은 저장해 둔 줄을 0원 표시(gone·was·on)로 바꾼다(`withdraw`). 표시는 rows에 실려 계정·다른 기기로 가고 합칠 때 늘 이긴다. 철회한 뒤 인게임 맞추기를 한 주(맞춘 날 > 철회한 날, 같은 날이면 보정값 음수)는 보정값에 그 금액을 되돌린다. 가져오기 기록에 `cash: {statuses, withdrawn, unpaired}`
- 북마크 버전: 북마클릿이 ping·`__mvpImport(ver)`·`#import-3`로 버전을 보낸다(2 이하는 없음). 옛것이면 가져오기 창에서 화면을 어둡게 하고 📥 단추만 비추는 안내(BmGuide), 새것이 처음 오면 '새 북마크 확인됐어요'. 마지막 버전은 localStorage `maplemvp.bmVer`. 개발 서버 콘솔 `__mvpBmTest(2|3)`로 띄워 볼 수 있다. 버전을 올리면 bookmarklet.ts VER와 store BM_NOW를 같이 올린다
- 운영자 텔레그램 알림(2026-11-05): 관리자가 아닌 사람이 새 문의·문의자 답글·해결됨을 하면 `tellAdmin()`(functions/api/_qna.ts)이 봇 @mvp_alarm_bot으로 운영자에게 제목·앞 300자·링크를 보낸다. 비밀값 TG_TOKEN·TG_CHAT(Cloudflare Pages)이 없으면 안 보내고, 실패해도 글쓰기는 그대로. 로컬 시험은 `pages dev`에 `-b TG_TOKEN=… -b TG_CHAT=…`를 더해 띄운다
- 절차: post(본문·diag) · reply · image · vault(rows·pcroom·plan·eff) 받기 → `test/private/<이름>.test.ts`로 재현 → 고침 → 시험(공개·비공개) → 로컬 화면으로 확인 → 배포(사용자 지시 뒤) → 필요하면 보정값 주입(허락 뒤)
- 조회 예: `npx wrangler d1 execute maplemvp --remote --json --command "SELECT * FROM post WHERE id=N"`
- 화면으로 확인: 따로 띄운 Chrome 프로필(puppeteer-core, headless)에서 localStorage에 rows·pcroom·syncedAt·plan·eff를 넣고, 시계를 그 시각으로 돌려(evaluateOnNewDocument로 Date 바꿈) 파일을 올려 저장까지. 끝나면 프로필 폴더 삭제. 사용자 브라우저 저장소는 건드리지 않는다
- 운영자 본인 계정 저장값: `SELECT v.* FROM vault v JOIN member m ON m.uid=v.uid WHERE m.admin=1` → docs/private/me/vault-<날짜>.json (읽기만)
- wrangler 첫 호출이 Authentication error [code: 10000]로 실패해도 다시 하면 된 적 있다(2026-10-15, 10-20, 11-02에도: whoami 뒤 다시 하니 됨 — 토큰 갱신 문제, 11-06에도). Claude Code 자동 모드는 운영 D1 읽기·git commit/push를 막은 적이 있다 → .claude/settings.local.json 허용 규칙(git commit·push·pull·add·status·log·diff, npx wrangler)에 맞는 명령만 묶어 보낸다. 그래도 막히면 사용자가 수동 모드로 바꾼 뒤 실행
- 사용자 로컬 데이터를 다른 PC로 옮길 때: 확인용 창(따로 띄운 프로필)의 localStorage를 덤프해 docs/private/me/local-<날짜>.json과 바탕화면에 두고 사용자가 직접 옮긴다. 다른 PC에서는 그 파일을 docs/private/me/에 넣고 확인용 창에 넣으면 된다. 운영 vault를 이 형식으로 바꾸면 rows·pcroom·syncedAt(JSON 문자열)·plan·eff
- 비공개 시험은 약 12분. 헤드리스 화면 확인과 같이 돌리면 dorolong이 5초 제한에 걸린다 — 따로 다시 돌려 확인
- 5199 포트에 다른 세션의 vite가 떠 있을 수 있다(새로 띄우면 포트 겹침으로 꺼짐). 떠 있는 서버도 지금 파일을 내보내니 그대로 써도 된다(바닥 빌드 표시는 옛 해시)
- 공지 팝업이 로고·단추를 가릴 수 있어 확인 스크립트에서는 `.scrim`을 지운다
