# 캡처 판독
언제 읽나: 인게임 툴팁 캡처·화면공유를 못 읽거나 잘못 읽는 문의, ocr.ts·ocrnet.ts를 고칠 때, 판독 모델을 다시 학습할 때

## 결정
- 2026-10-12 학습 모델(ocrnet)을 글자 판독과 **같이** 돌린다 — 글자를 잘라 맞추는 규칙(밝기·틈·회색 '캐시')이 캡처 상태마다 깨져 문의마다 땜질했다. 사용자가 '브라우저에서 도는 작은 모델'을 골랐다
- 2026-10-12 서버에서 Claude API로 읽는 방식은 쓰지 않는다 — 누가 마구 올리면 비용이 사용자 부담이고 수익이 없는 서비스라서(사용자 기각)
- 2026-10-12 화면공유는 모델을 '필요할 때만' 돌린다(scan의 'fallback') — 매번 돌리면 CPU·메모리는 괜찮지만 한 장 2.2초라 화면공유가 느려진다. 필요할 때만 = 글자 판독이 표를 못 찾았거나, 흔들리거나(8표 미만·2등의 3배 미만), 값이 말이 안 될 때(아래로 갈수록 줄거나 한 줄 250만 초과). 이 조건으로 정확도가 매번 돌리는 것과 같았다(106/112)
- 2026-10-12 파일·붙여넣기 판독은 워커에서 늘 모델까지('always') — 한 장이라 1~2초 늘어도 괜찮고, 화면이 멈추지 않게 워커로
- 2026-10-12 모델 판독은 한 표 40(NET_VOTES)으로 글자 판독 후보에 더한다 — 같으면 확정, 다르면 모델이 앞서되 '확실한 판독' 문턱을 못 넘어 다시 찍어 달라고 하기 쉽다(틀린 값 저장보다 낫다)

## 주의
- 모델의 표 자리는 `findSpans`(점수로 거르지 않음)를 쓴다. 글자 판독용 `findTables`의 점수가 HDR 캡처 금액 열을 0점으로, 고정 픽셀 기준(글자 높이 8px)이 작은 캡처 줄을 떨궜다
- 열 고르기: 오른쪽부터 12줄 모두 숫자(250만 이하)인 열. 숫자 열이 둘이면 블랙(왼쪽 = 유지까지, 오른쪽 = 사용 이월). findSpans가 같은 열을 두 번 줄 수 있어 겹치는 열은 하나만
- 밝게 보정한(HDR) 캡처: 툴팁 바탕 90 이상이고 회색 '캐시'가 어느 열에도 없으면 washed. 바탕 밝기로 보정을 거꾸로 계산해 되돌린다(v' = a·v + b, 바탕→57, 꽉 참→180). 표 자리는 되돌리기 **전** 것을 쓴다(되돌린 뒤 다시 찾으면 금액 열을 놓쳤다)
- washed에서 '캐시' 떼기: 가장 넓은 틈이 띄어쓰기 폭 이상이고 그 앞 틈들·바로 뒤 틈의 1.5배를 넘을 때만. 끊고 한 글자만 남으면 그 글자가 넓어야('0') 한다('1' 양옆 틈 때문에 '1,109,330'이 '1'로 잘렸다)
- 블랙 잔액 줄: 숫자 덩어리는 넓게(s(12)) 잇고, 회색 '10,000,000' 확인은 좁게(s(7)). '1' 양옆이 넓어 '9,211,100'이 '100'으로 읽혔다
- 학습 자료 만들 때 날짜 열('2026-10-15')을 지우지 말 것 — 금액이 아닌 열이라 '빈 답' 예시로 남겨야 한다(한 번 실수로 지웠다)
- 합성 줄의 '캐시' 뒤 여백·비친 글자가 실제와 다르면 끝에 0이 붙는 오독이 났다(반투명 툴팁이라 뒤 게임 글자가 비친다)
- ocrnet.ts의 입력 손질(prep)은 train.py와 똑같아야 한다. 바꾸면 `test/private/ocrnet-parity.test.ts`로 파이썬=TS 확인
- 판독이 느려져 비공개 시험 일부는 시간 제한을 300초로 늘려 둠

## 현재 방식
- `frontend/src/lib/core/ocr.ts`: scan(g, fallbackScale, net) = scanGlyphs(글자 판독) + netColumns(모델)
- `frontend/src/lib/core/ocrnet.ts` + `ocrnet.weights.json`(약 1MB, float16): 합성곱 + CTC, 한 줄 약 40ms(CPU)
- 워커 `web/ocr.worker.ts`에만 실려 첫 화면은 안 무거워진다
- 학습 도구 `tools/ocrnet`: glyphs.py(실제 줄에서 숫자 조각) → synth.py(이어 붙이고 크기·흐림·밝기·HDR·JPEG·비친 글자로 망가뜨림) → train.py(GPU 40,000단계 약 20분) → export.py. 자료는 `docs/private/ocrset`에만
- 다시 학습: `test/private/dump-rows.test.ts`로 정답 줄·비금액 열 다시 뽑기 → glyphs.py → train.py → export.py → ocrnet-parity · compare-ocr(252장) · 비공개 시험 · 화면 확인(e2e)
